# Contributing to Awesome Ergo

Thanks for helping build the definitive Ergo ecosystem resource!

## Quick Start

1. Fork this repository
2. Add your project to the appropriate section
3. Open a Pull Request

> **Note:** This list is for ecosystem projects. Documentation lives at [ergodocs](https://github.com/ergoplatform/ergodocs).

## Adding a Project

### Format

```markdown
- [Project Name](https://github.com/link) - One-line description
```

### For Categorized Sections

Follow the existing table or list format in each category.

## Categories

- **🏗️ Core Infrastructure** - Nodes, oracles, bridges
- **💼 Wallets** - Browser, desktop, mobile, utilities
- **📚 SDKs & Libraries** - Development tools
- **🛠️ Development Tooling** - Smart contracts, frameworks
- **🎮 Applications** - DApps and user tools
- **📖 Learning** - Tutorials and resources

## Quality Criteria

**Accepted:**
- ✅ Active project with working URL
- ✅ Relevant to Ergo ecosystem
- ✅ Community-verified

**Not accepted:**
- ❌ Dead links
- ❌ Unrelated projects
- ❌ Scam/phishing sites

## Pull Request Checklist

- [ ] Project is Ergo-related
- [ ] URL works
- [ ] Added to correct category
- [ ] Description is concise
- [ ] Not a duplicate

## Style Guide

- Keep descriptions short (one line)
- Use working URLs only
- Follow existing formatting
- Sort alphabetically within sections
